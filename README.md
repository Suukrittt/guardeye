# GuardEye – Replit + GitHub bundle
1. Replit: Create Repl > Import/upload this folder > open PROMPT.md and paste it into Replit Agent.
2. Web app: `python3 server.py` (serves web/). Deploy for an https link, then install it from Chrome on Android or Windows.
3. APK + Windows EXE: push to GitHub; Actions tab > latest run > Artifacts (GuardEye-debug-apk, GuardEyeMonitor-exe).
Status: web logic tested in Node; android/ and windows/ not run on real devices; workflows not yet executed.
